# Security and privacy

The tools in this repository handle personal health data: workouts, body measurements and similar records exported from fitness apps.

## Reporting a problem

If you find a security problem, or a way a tool could expose someone's data, please report it privately through [GitHub's private vulnerability reporting](https://github.com/zeusal/Sparky-tools/security/advisories/new) instead of opening a public issue.

## Your data

- The tools run on your own computer and don't upload anything.
- Never attach a real export to an issue or pull request. If a problem only shows with your file, share a few rows with the values changed.
- Keep your original export until you have checked the result in SparkyFitness.
