Hevy to SparkyFitness

Bring your Hevy history to SparkyFitness

This page turns your Hevy workout export into a file that SparkyFitness can import, with your sets, reps, weights and cardio. It takes about five minutes, works on a computer or a phone, and there's nothing to install.

Hevy export"5 Dec 2025, 11:37", "Bench Press (Barbell)", set 0, 135 lb
→
Ready for SparkyFitness2025-12-05, Bench Press (Barbell), set 1, 61.23 kg

Your workouts stay on your device. Everything happens inside your browser; nothing is uploaded anywhere.

What you need

Your Hevy accountThe free plan is fine. No Hevy Pro needed.
Your SparkyFitness accountYou'll import the file on the SparkyFitness website.
A computer or a phoneAny recent browser: Chrome, Edge, Firefox or Safari.
About five minutesA bit longer if you choose exercise names in step 3.

1 Get your workouts from Hevy

  • On your phone: in the Hevy app, open Profile → Settings (gear icon) → Export & Import Data → Export Data → Export Workouts. Your phone then asks where to put the file: save it to Files (iPhone) or Downloads (Android), or send it to yourself by email to open it on a computer.
  • Or on a computer: sign in at hevy.com/settings?export and press Export Workout Data. This file always has the exercise names in English.

Don't open the file in Excel or Numbers and save it: that changes the dates. Then choose it here:

2 Choose your SparkyFitness units

Pick the units your SparkyFitness account uses. To check, open SparkyFitness and go to Settings → Preferences: look at Weight Unit and Distance Unit. It doesn't matter which units you used in Hevy; they're converted.

3 Exercise names Optional

  • New to SparkyFitness? Skip this step. Your exercises keep their Hevy names, for example Bench Press (Barbell), and you keep using them in SparkyFitness.
  • Already logging workouts in SparkyFitness? Then choose here which of your SparkyFitness exercises each Hevy exercise is, so your old and new history end up together. SparkyFitness only links them when the name is exactly the same, capitals included, and it can't merge exercises later, so do it here.
  • The same exercise twice in Hevy? For example Pull Up and one you created yourself, Pull-up. Give both the same name and they become one exercise in SparkyFitness, with all their sets. The table points out names that look alike and joins them with one click.

Choose your Hevy file in step 1 to see its exercises here.

First, list the names of your SparkyFitness exercises (recommended)

Type here, one per line, the names of the SparkyFitness exercises you also did in Hevy, exactly as they appear in SparkyFitness under Exercises. You only need the ones you want your Hevy history joined to. The table below then suggests the right name for each Hevy exercise and warns you about typos. This list stays in this browser.

SparkyFitness doesn't let you select text in its exercise list. To copy a name instead of typing it, open the exercise there (double-click it on a computer, tap it on a phone), copy it from the Name box and close the window with Cancel.

Not carried over: the grouping into workouts (each exercise becomes its own diary entry for that day; two workouts with the same exercise on one day are combined), the time of day, calories (Hevy doesn't export them, so imported entries show 0 kcal), and muscle groups and equipment, which you can add to the new exercises in SparkyFitness.






  
If something goes wrong

  

    

      SparkyFitness says “Some entries failed to import.”
      

        
Everything else was imported. It's almost always an assisted exercise (such as Pull Up (Assisted)) that already exists in your SparkyFitness as a normal weighted exercise.

        
Either: in SparkyFitness, open that exercise, set Tracking type to Bodyweight (+/− weight), and import the same file again (nothing gets duplicated). Or: in step 2 here, open Advanced options, tick the assistance option, create the file again and import it.

      

    

    

      A “Map CSV Headers” window appears in SparkyFitness
      
You chose the file from Hevy instead of the one from step 4. Cancel and choose the file whose name ends in _sparkyfitness.csv.

    

    

      This page says it can't read the dates
      

        
Export the file from Hevy again and choose it here without opening it in another app first. Dates are read in English, Spanish, Italian, German, French, Portuguese, Dutch, Chinese, Japanese and Korean. For another language, export from hevy.com with the website in English.

        
If the dates look like 03/12/2023, the file was saved by Excel: export it again, or choose the date order under Advanced options in step 2.

      

    

    

      I imported the same file twice
      
That's fine. With the same file and the same exercise names, SparkyFitness updates what it imported before instead of adding it again.

    

    

      I have the same exercise twice in SparkyFitness
      
SparkyFitness can't merge two exercises yet. If one of them came from this file, delete that one in SparkyFitness and choose Delete including history (this also deletes any sets you logged on it by hand). Then, in step 3 here, give its Hevy exercise the name of the one you keep, create the file again and import it. What you imported before is updated, not added twice.

    

    

      I want other exercise names after importing
      
Importing again with new names would give you everything twice. First, in SparkyFitness, delete the exercises that came from Hevy and choose Delete including history. Then choose the names in step 3 here, create the file again and import it.

    

    

      The import showed an error after a long wait
      
SparkyFitness may still be finishing. Wait a minute and check your diary. Importing the same file again is safe if something is missing.

    

    

      Is my data safe?
      

        
Your file is read and converted inside your browser and is never uploaded. This page only remembers, in this browser, your units, your list of SparkyFitness exercise names and the names you chose.
