Move your Hevy history to SparkyFitness

Hevy lets every account, free or Pro, export its workouts as a CSV file. SparkyFitness can import workout history from CSV, but not Hevy's file as it comes: the dates carry a time of day and the columns have other names. A small converter rewrites the file on your own computer, and then SparkyFitness imports it like any other.

Hevy export"5 Dec 2025, 11:37", "Bench Press (Barbell)", set_index 0, weight_lbs 135
→
Converted for SparkyFitness2025-12-05, Bench Press (Barbell), set 1, weight 61.23 (kg)

Not used to the command line?

Use the easy version instead: it does all of this in your browser, on a computer or a phone, with nothing to install. Your file stays on your device.

Use the easy version

This page is for people who prefer to run the Python script themselves. Both give exactly the same file.

  1. 1

    Export your workouts from Hevy

    • In the app: Profile → Settings → Export & Import Data → Export Data → Export Workouts. You get workout_data.csv. Save or send it to your computer.
    • Or on the website: sign in at hevy.com, open hevy.com/settings?export and press Export Workout Data. You get workouts.csv.

    The app writes exercise names in the app's language; the website always uses English names. If your app is not in English, the website export is usually the better choice.

    Don't save the file in Excel or Numbers. Opening it to look is fine, but saving changes the dates and the emojis. If you already did, export again.

  2. 2

    Check your units in SparkyFitness

    Open Settings → Preferences and look at Weight Unit and Distance Unit. SparkyFitness reads imported weights and distances in those units, so the converter writes them that way, whatever units you used in Hevy.

    Set the same units in Your setup above.

  3. 3

    Get Python and the converter

    • Install Python from python.org/downloads. The main button installs the Python install manager. When it has finished, open a new Command Prompt and run py --version; if it offers to install Python, accept. (With the standalone installer instead, tick Add python.exe to PATH on its first screen.)
    • Open Terminal and run python3 --version. If it prints 3.8 or higher you're set. If not, install Python 3: on a Mac from python.org/downloads, on Linux with your package manager (for example sudo apt install python3).
    Download {{SCRIPT}} Read the code and documentation

    It's a single Python file that uses only Python's standard library. If your browser asks whether to keep it, choose Keep.

    Put hevy_to_sparkyfitness.py and workout_data.csv in the same folder, then open a terminal in that folder:

    • Open the folder in File Explorer, click the address bar, type cmd and press Enter.
    • Open Terminal, type cd followed by a space, drag the folder onto the window and press Return.
  4. 4

    Use exercises you already have Optional

    SparkyFitness reuses one of your exercises only when the name matches exactly, capitals included. Any other name becomes a new exercise in your library, named as in Hevy, for example Bench Press (Barbell). SparkyFitness can't merge two exercises later, and progress charts follow one exercise.

    • New to SparkyFitness? Skip this step and keep logging under the Hevy names after the import.
    • Already logging in SparkyFitness under other names? Match the names now, so your old and new history end up under the same exercise.

    Make the table:

    python3 hevy_to_sparkyfitness.py workout_data.csv --list-exercises

    This writes workout_data_exercises.csv, with one row for each exercise in your Hevy history. Open it in Excel, LibreOffice or Numbers:

    • In sparkyfitness_name, type the exact name of the SparkyFitness exercise to use. Spelling and capitals must match. SparkyFitness doesn't let you select text in its exercise list, so type it, or open the exercise there (double-click it, or tap it on a phone) and copy the name from its edit window.
    • Leave it empty to keep the Hevy name. Several Hevy names can point to the same exercise.
    • The sets, last_done and kind columns are there to help you decide. You only need to fill in the exercises you care about.
    • Save it as CSV UTF-8 (in Excel: File → Save As → CSV UTF-8 (Comma delimited)).
    • If Excel shows each row in a single column, open the file with Data → From Text/CSV instead, or use LibreOffice or Google Sheets.

    Running the same command again later, for example with a newer export, keeps every name you filled in and adds any new exercises.

    Then tick “I filled in an exercise table” in Your setup.

    Assisted exercises such as Pull Up (Assisted) are written as a negative weight, which SparkyFitness reads as assistance. If you point one to an exercise you already have, that exercise needs the Tracking type Bodyweight (+/− weight).

  5. 5

    Convert the file

    python3 hevy_to_sparkyfitness.py workout_data.csv --weight kg --distance km

    This writes workout_data_sparkyfitness.csv in the same folder and prints a short summary. Read it: it says which units it used, which exercises it treated as cardio, timed holds, bodyweight or assisted, and anything it couldn't handle. For example:

    Wrote 2184 sets from 96 workouts (2024-03-02 to 2025-12-05) to workout_data_sparkyfitness.csv
Units: file in lbs/miles, written in kg/km.
Cardio: Running, Treadmill
Timed holds: Plank
Bodyweight: Chin Up, Hanging Leg Raise, Pull Up
Assisted (assistance written as a negative weight): Pull Up (Assisted)
Written with a negative weight (assistance): Pull Up (Assisted). If SparkyFitness then
says 'Some entries failed to import.', the rest was imported and ...

    If it stops with an error, see If something goes wrong. Nothing has changed in SparkyFitness yet.

  6. 6

    Import it into SparkyFitness

    1. Open SparkyFitness in your browser and go to Settings → Data Import.
    2. Next to Workout History (CSV), press Import.
    3. Choose workout_data_sparkyfitness.csv, the converted file, not the one from Hevy. Press Process File.
    4. Leave the format options on Auto-detect. No “Map CSV Headers” window should appear. If one does, you picked the original Hevy file.
    5. Check the preview: dates, sets, reps and weights.
    6. Press Confirm and Import. A few years of history can take a minute or two. Keep the page open until it finishes.
  7. 7

    Check your history

    Open the diary on a few days you remember and compare them with Hevy. The new exercises are in your exercise library. You can edit them to add muscles and equipment, which Hevy's export doesn't include.

What comes across

In HevyIn SparkyFitness
Workout dateDiary date (the day the workout started)

Warm-up, drop and failure setsSet types Warm-up, Drop Set and Failure
RPE and supersetsSet notes, for example “RPE 8; Superset 1”
Workout title, description, exercise notesNotes on each exercise entry
Assisted exercisesA bodyweight exercise with a negative weight (the assistance)
Cardio and timed exercisesExercises tracked by duration and distance, or by duration

Not carried over:

  • The grouping into workouts. Each exercise is its own diary entry for that day. Two workouts with the same exercise on one day are merged into one entry, with the sets in order.
  • The time of day.
  • Calories. Hevy doesn't export them, so imported entries show 0 kcal.
  • Muscle groups and equipment.

If something goes wrong

“python is not recognized” or “command not found”

On Windows, use py (the commands on this page already do). If it still isn't recognized, close and reopen the Command Prompt, or install Python again from python.org/downloads. On a Mac or Linux, use python3. Or skip Python and use the easy version.

“could not read the date …”

Export again from Hevy and don't edit the file. The converter reads Hevy's dates in English, Spanish, Italian, German, French, Portuguese, Dutch, Chinese, Japanese and Korean. For any other language, switch the Hevy app or website to English and export again.

“the dates look like 03/12/2023 …”

The file was saved by Excel, which rewrote the dates. Use the original export from Hevy. If you can't, add --date-order dmy when the day comes first, or --date-order mdy when the month comes first.

The import says “Some entries failed to import.”

Everything else was imported. Usually one of the exercises the converter wrote with a negative weight (the assistance of an assisted exercise) already exists in SparkyFitness as a weighted exercise. The converter lists those exercises at the end of its summary.

In SparkyFitness, edit that exercise, set Tracking type to Bodyweight (+/− weight), and import the same file again. Nothing is duplicated. Or convert again with --assisted-positive; the assistance then shows as the weight.

I want other exercise names after importing

Importing again under new names would duplicate your history. First delete the imported exercises in your exercise library and choose Delete including history. Then make an exercise table (step 4), convert again and import.

I imported the same file twice

That's fine. With the same file and the same exercise names, SparkyFitness updates the entries it imported before instead of adding new ones.

The import showed an error after a long wait

The server may still be finishing. Wait a minute, then check the diary. Importing the same file again is safe if something is missing.
