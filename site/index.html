Sparky Tools

Small, unofficial tools for people who use SparkyFitness, the self-hosted fitness and nutrition tracker. Each one solves a single practical problem, such as bringing your history over from another app.

How the tools are built

Your data stays with youTools run on your own computer and upload nothing.
Few requirementsPython's standard library where possible, so there is nothing else to install.
Safe by defaultYour original file is never overwritten, and ambiguous input stops with a clear message.
Documented and testedEvery tool has full documentation, a changelog and automated tests.

Questions and ideas

Found a problem, or have an idea for a tool? Open an issue. Please don't attach your real exports: they contain personal health data.

Not part of the SparkyFitness project, and not affiliated with it or with the apps the tools read data from.
